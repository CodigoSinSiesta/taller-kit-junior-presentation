# Diapositiva 27 · Adaptar

**Tiempo:** 2 min

## Tesis

Un tutor útil es el que se parece a tu trabajo.

## Mensajes clave

- Perfil: qué sabe de ti. Plantillas y comandos: cómo se comporta. `tutor.md`: qué puede hacer.
- Ejemplo probado: con un perfil de Java, el tutor comparaba con Java sin que se lo pidieran.
- La instalación personal usa enlaces: basta con editar el repo del kit.
- Un comando nuevo necesita volver a ejecutar `instalar.sh`.
